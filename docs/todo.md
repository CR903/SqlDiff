## 深度功能：

作为付费功能的深度功能，用户可以享受以下高级服务：
1. `preflight`功能。
2. **大模型分析**：通过JEV(`决策性模型`)来快速分析生成的SQL语句在执行时的潜在问题，进一步为 `preflight` 提供更全面的分析和建议。
2. **接入云同步功能**：对接`WebDAV`和`S3 兼容存储`两种方式云同步功能，通过云同步在多设备之间共用节点库。
   - 同步方式只能二选一，不能同时使用，切换需提醒用户会禁用另一种方式
   - 支持同步方式测试连接
   - 支持保存同步配置，同步配置包括服务商、服务地址、账号、密码、远程根目录、配置名称
   - 支持选择自动同步，支持手动上传到云端和从云端下载。开启自动同步后，当节点库发生变化时，自动同步会在后台进行上传节点库，确保多设备之间的数据一致性
3. **多语言支持**：支持中文、英文、日文、韩文等多种语言，以便用户在不同语言环境下使用我们的工具。
4. **节点库限制**：为了防止用户滥用付费功能，我们计划对节点库进行限制，例如每个用户只能创建和管理一定数量的节点库，超过限制后需要付费升级。免费版支持5个节点库，付费版支持无限个节点库。
5. **多数据库支持**：支持MySQL、PostgreSQL、SQL Server、Oracle、MongoDB等多种数据库，以便用户在不同数据库环境下使用我们的工具。但目前仅限同类型数据库之间对比，不支持跨类型数据库对比。

## 海外上线计划：

由于国内对工具类软件付费限制(需祖册公司能才能开通付费功能)，所以我们计划在海外上线付费功能，以满足全球用户的需求。海外上线前有几样需要注意的事项：
1. **工具网站**：我们需要在Cloudflare上建立工具网站，以便用户可以访问和使用我们的工具。
2. **支付方式**：海外上线后，我们需要支持多种支付方式，例如信用卡、PayPal、Apple Pay等。这个需要去了解开通海外支持有什么限制和相关手续。
3. **客服支持**：海外上线后，我们需要提供24小时客服支持，以解决用户在使用过程中遇到的问题。
4. **工具定价**：默认免费使用免费功能，但付费功能需要按月订阅和永久性订阅。先定价按月1美元，永久性订阅5美元，然后根据市场反馈和用户需求进行调整。
